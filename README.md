# Axelrod Lab

Локальная веб-песочница для повторяющейся дилеммы заключённого. Логика турниров и отдельных матчей работает через FastAPI и `Axelrod-Python`; данные не сохраняются и база данных не нужна.

## Запуск

Нужен Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

Откройте `http://127.0.0.1:8000`.

Не запускайте `static/index.html` через Live Server (обычно это `http://127.0.0.1:5500`).
Он не обслуживает API приложения и может вернуть HTML вместо CSS/JavaScript, из-за чего
браузер показывает ошибку MIME-типа. Страницу, стили и скрипт должен отдавать FastAPI на порту 8000.

## Что есть в первой версии

- Выбор восьми известных стратегий Axelrod.
- Настройка числа раундов, повторений и шума.
- Круговой турнир, ранжирование по среднему счёту и наглядные полосы сравнения.
- Детальный матч двух стратегий с историей каждого раунда.
- Ограничения параметров на API, чтобы случайно не запустить слишком тяжёлую симуляцию.

Публичный сервер не выполняет произвольный код пользователя: это сознательное ограничение безопасности. Для такой функции нужен отдельный изолированный runtime.
